## 1. 背景と動機

FireAlpaca には公式に中国語表示機能があります（**ヘルプ → 言語 → 中国語（簡体字）／（繁体字）**）。
しかし実際に切り替えて使ってみると、**簡体字・繁体字ともに翻訳が中途半端**であり、
未翻訳の UI 文字列は実行時に英語へ戻ってしまいます。私は日々このソフトを使う者として、
この欠落を補う翻訳データを作成し、公式での取り込みをご提案したく本資料をまとめました。

## 2. 確認した事実

1. **中国語文字列はバイナリに内蔵済み**ですが、**カバー率は約 50–65%** に留まります。
   文字列は各グループ内で `ja → zh-CN → zh-TW → ko` の順に格納されており、
   グループごとに比較すると中国語 2 言語とも**約 30–50% が欠落**しています
   （例：「カラー」メニューグループは日本語 15 文字列に対し中国語は 1 文字列のみ）。
2. **ビルドパイプラインの不具合**と思われる現象を確認しました：
   **簡体字中国語 6 文字列（图层/粘贴/文件夹/边框/滤镜/模板）が、zh-CN ブロックではなく
   日本語ブロックの末尾に付加**されています（過去の増分パッチが誤ったテーブルに配置されたものと推定）。

## 3. ご提供する翻訳データ（いずれもデータのみ）

| ファイル | 内容 |
|---|---|
| `po/zh_CN.po` | gettext カタログ。**2,672 エントリ**（msgid = 日本語 UI 文字列、msgstr = 簡体字中国語）。`Ctrl/Shift/Alt` キー・`(&X)` ニーモニック・数字は保持 |
| `po/zh_TW.po` | 同上。**2,672 エントリ**、msgstr = 繁体字中国語 |
| `firealpaca-glossary.tbx` | TBX-Basic 形式の 4 言語用語集（ja / ko / zh-CN / zh-TW、2,672 概念） |
| `firealpaca-l10n-worktable-final.csv` | 4 言語対照表（全 UI 文字列一覧。バイナリ内のグループ・位置情報付き） |

すべて公開リポジトリから取得・閲覧できます：**https://github.com/dororo42/firealpaca-zh-l10n**

## 4. 用語の基準

用語はコミュニティで定着している **Krita および Blender** の中国語翻訳に準拠しました
（レイヤー/圖層、マスク/蒙版・遮色片 など）。繁体字については台湾の慣習
（滑鼠/資料夾/影像/預設）に合わせ、Blender の `zh_TW.po` や Krita の zh_TW 用語を参照しています。

## 5. 取り込み方法（ご提案）

- ビルドがソースの文字列テーブルで管理されている場合、CSV/PO は**日本語の原文文字列**で突合できます。
  CSV の `group/idx` キーは 2.16.3 バイナリ内の正確な位置を指しており、検証にお役立ていただけます。
- XLIFF やプレーンなリスト、特定の CSV 列順など、御社のパイプラインに合わせた形式への変換も可能です。
- 公式翻訳者による用語の修正など、フィードバックをいただければ喜んで修正・再提出いたします。
